## Features

We have added a new query `productSets` that will return a simplified version of the 8.SET and 8.SET Custom content combined. The response can be used as as if you want to show paginated product sets.

Check out the [example page](../examples/8.set-simplified.md).

Also keep in mind that the [schema](../general/graphql-schema.md) of the respective nodes is different compared to the classic `customSets` or `matchingProductClusters` queries.
